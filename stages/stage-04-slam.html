Stage 04 • World Referencing

Global Map Localization

Resolves global pose against an environment map. Exactly one node owns the map -> odom transform: slam_toolbox during mapping, or AMCL seeded by ArUco markers during localization.

Detailed Sequential Sub-Steps

Step 4.1
Rate: On Detection Frame: map

ArUco PnP Global Pose Seeding

aruco_localizer_node detects wall-mounted ArUco fiduciary boards via OpenCV solvePnP, computes T_map_base, and publishes /initialpose when robot is stationary.

Step 4.2
Rate: 10-20 Hz Frame: map -> odom

Particle Filter Update (AMCL)

KLD-sampling Adaptive Monte Carlo Localization evaluates 240 laser beams against static likelihood field, publishing map -> odom correction.

Step 4.3
Rate: 5 Hz Frame: map -> odom

Pose Graph SLAM (Alternative)

async_slam_toolbox_node runs scan-matcher frontend and Ceres nonlinear optimizer backend to build rolling occupancy grid /map.

# AMCL owns map -> odom. This node only provides /initialpose then gets out of the way.
pose_msg = PoseWithCovarianceStamped()
pose_msg.header.stamp = self.get_clock().now().to_msg()
pose_msg.header.frame_id = "map"
pose_msg.pose.pose = t_map_base
pose_msg.pose.covariance[0] = 0.05   # x variance: 5 cm
pose_msg.pose.covariance[7] = 0.05   # y variance: 5 cm
pose_msg.pose.covariance[35] = 0.02  # yaw variance: ~8 deg
self.initial_pose_pub.publish(pose_msg)
