Stage 10 • Autonomous Navigation

Nav2 Planning & Motion Control

High-level path planning and trajectory execution. Nav2 Server manages global path generation (Theta*, Smac) and local control (RotationShim + DWB or MPPI) with traversability awareness.

Detailed Sequential Sub-Steps

Step 10.1
Rate: 10 Hz Frame: odom

2.5D Elevation Traversability Classification

traversability_node analyzes terrain step heights, slopes, and negative obstacles (craters) to emit lethal point clouds for costmap ingestion.

Step 10.2
Rate: 1 Hz / Goal Trigger Frame: map

Global Collision-Free Path Planning

planner_server calculates optimal geometric path across global costmap using Theta* or SmacPlanner2D with Euclidean heuristic.

Step 10.3
Rate: 20 Hz Frame: base_link

Rotation Shim Angular Alignment

When path deviation angle > 45° (0.785 rad), RotationShimController forces zero linear speed and commands in-place skid rotation first.

Step 10.4
Rate: 20 Hz Frame: base_link

Model Predictive Path Following (MPPI / DWB)

Evaluates thousands of sampled trajectories over 32 time steps (dt=0.05s) minimizing cost penalties for obstacle proximity, goal distance, and smooth speed.
