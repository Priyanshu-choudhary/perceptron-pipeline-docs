Stage 07 • State & Identity Filtering

Multi-Object Tracking

Tracks fused 3D objects over time in odom frame using constant-velocity Kalman filters, Hungarian assignment with Mahalanobis gating, and track lifecycle state machines.

Detailed Sequential Sub-Steps

Step 7.1
Rate: 10 Hz Frame: odom

Ego-Motion Compensation (TF Buffer)

Transforms object centroids from base_footprint to odom at detection timestamp using non-blocking asynchronous queue to prevent TF stalls.

Step 7.2
Rate: 10 Hz Frame: odom

Mahalanobis Distance Gating

Evaluates innovation covariance S = H P H^T + R; gates candidate detections using Chi-squared threshold (chi2 = 9.21 for 99% confidence).

Step 7.3
Rate: 10 Hz Frame: odom

Hungarian Optimal Assignment

Constructs cost matrix from Mahalanobis distances and executes SciPy linear_sum_assignment to match detections to active tracks.

Step 7.4
Rate: 10 Hz Frame: odom

Track Lifecycle State Machine

Transitions tracks: TENTATIVE (hits < 3) -> CONFIRMED (active updates) -> COASTING (misses <= 10) -> DELETED.

# TrackedObject.msg state definitions:
uint8 TENTATIVE=0   # seen, not yet confirmed: do not plan around it yet
uint8 CONFIRMED=1   # updated by a detection this frame
uint8 COASTING=2    # confirmed, not seen this frame: position is a prediction

# tracker.py: Mahalanobis gating
diff = z - H @ x_pred
S = H @ P_pred @ H.T + R
chi2 = diff.T @ np.linalg.inv(S) @ diff
if chi2 <= 9.21: # 99% gate for 2 degrees of freedom
    accept_match()
