Stage 08 • Spatio-Temporal Horizon

Trajectory Prediction

Projects confirmed dynamic objects forward across multiple horizons (0.5s, 1.0s, 2.0s) using Constant Velocity (CV) and Constant Turn Rate (CTRV) models with expanding error ellipses.

Detailed Sequential Sub-Steps

Step 8.1
Rate: 10 Hz Frame: odom

Dynamic Moving Speed Gating

Classifies tracks as dynamic only when speed exceeds 2-sigma velocity uncertainty (speed > 2 * sqrt(var_v)), preventing jittering static poles from predicting paths.

Step 8.2
Rate: 10 Hz Frame: odom

Motion Model Selection (CV vs CTRV)

Applies Constant Velocity (CV) for linear movement, and Constant Turn Rate Velocity (CTRV) for vehicle tracks with measured yaw rate |w| > 0.1 rad/s.

Step 8.3
Rate: 10 Hz Frame: odom

Covariance Error Ellipse Inflation

Propagates covariance forward in time: Sigma(t) = F(t) * P * F(t)^T + Q(t), showing expanding spatial uncertainty at future horizons.

Step 8.4
Rate: 10 Hz Frame: odom

Dense Waypoint Ribbon Generation

Interpolates path waypoints at dt = 0.1s from t=0 to t=2.0s for downstream voxel costmap rasterization.

Core Algorithmic Implementation 

# prediction.py: CTRV closed-form forward projection
def predict_ctrv(x, y, yaw, v, w, dt):
    if abs(w) < 1e-4: # fallback to CV for zero yaw rate
        return x + v * math.cos(yaw) * dt, y + v * math.sin(yaw) * dt, yaw
    theta = yaw + w * dt
    x_new = x + (v / w) * (math.sin(theta) - math.sin(yaw))
    y_new = y + (v / w) * (-math.cos(theta) + math.cos(yaw))
    return x_new, y_new, theta
